HOW TO EDIT ON GITHUB
1. Open your GitHub repository.
2. Click Add file > Upload files.
3. Upload index.html, style.css, and script.js (upload the files themselves, not only this ZIP).
4. Scroll down and click Commit changes.
5. If these files already exist, open a file in GitHub and use the pencil icon to edit it, then click Commit changes.

HOW TO PUBLISH WITH GITHUB PAGES
1. In the repository, click Settings.
2. Click Pages on the left.
3. Under Build and deployment, select Deploy from a branch.
4. Choose branch main and folder /(root), then click Save.
5. Wait a few minutes. GitHub will show your website address in the Pages section.
